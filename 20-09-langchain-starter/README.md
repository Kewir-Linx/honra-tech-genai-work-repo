### Langchain Starter Task

The goal is simple:
Create an app that allows users to chat with an LLM on a particular topic. It could be music, food, sports, news.
- Use `FASTapi` to expose an endpoint that allows for the communication.
- Send the prompt and receive the model's response for display on a `Streamlit` frontend.
- Use `langchain` to interact with the model on the backend.

Just a simple app, that's it.

**Make sure to create a folder with your name in this [folder](./)**
Add your own `.env`:
```
cd 20-09-langchin-starter
cp .env.example .env
```

> Follow the instructions in the repo's [README](../README.md) to set up your environment.
